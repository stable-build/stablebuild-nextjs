## Copy Rules

Use these angles consistently:

- Lead with shipped systems, live deployments, adoption, and findings
- Prefer exact proof points over abstract claims
- Emphasize that the same team handles product, protocol, AI, and security
- Avoid generic agency language like "end-to-end solutions" unless immediately backed by a concrete example
- Treat production breadth and security depth as the main differentiators

## Good Site-Level Claims

- Built for live users, not just internal demos
- Product, AI, and protocol work handled by the same senior team
- Security review thinking is built into delivery
- Comfortable owning unfamiliar stacks under real deadlines
- Strongest when work spans UI, infra, contracts, and AI in one system
